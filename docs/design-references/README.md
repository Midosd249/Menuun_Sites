# Visual reference screenshots — SIMT demo

These nine owner-provided mobile screenshots were reviewed as design references for the fictional SIMT Barber House demo. They are stored under documentation, not `public/`, so they are not served as customer-facing site assets.

## Reference lock

**Dominant traits to adapt**
- Deep forest-green / near-black hero and closing CTA surfaces.
- Warm ivory and sand content sections with restrained gold detailing.
- Clear teal primary booking action, especially on mobile.
- Arabic-first headline hierarchy and compact mobile navigation.
- Real photography used as part of service discovery, not just as decoration.
- Distinct sections for services, groom package, team, portfolio, and location.
- Persistent but non-blocking booking affordance.

**SIMT-specific synthesis**
- Keep the SIMT name and its own content rather than copying MAREA's brand identity, wordmark, exact copy, or page composition.
- Preserve the existing cinematic full-bleed hero and simulated booking flow.
- Add owner-supplied photography to service rows, the gallery, team, and location; use the supplied MP4 as progressive desktop enhancement.
- Keep the still poster for phones and reduced-motion visitors, and provide a pause/play control for the film.
- Prices, team identities, address, hours, and all booking data remain fictional demo content.

## Research beyond the supplied screenshots

- [Gentry House Barbers case study](https://sr7webdesign.co.uk/our-work/gentry-house-barbers/) — progressive enhancement for cinematic hero media, a still-first mobile experience, explicit reduced-motion handling, and an accessible pause control.
- [Polyakov Barber case study](https://levitskiy.dev/en/work/polyakov) — image-led craft storytelling and disciplined use of photography.
- [The Atelier — Cinematic Barbershop Experience](https://apalaugonzalez.com/work/atelier) — deep ink/forest contrast, restrained brass accents, and carefully controlled motion.

These references inform design decisions only; no source code or exact brand assets are copied.
