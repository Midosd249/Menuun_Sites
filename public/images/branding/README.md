# Brand assets — Atelier Noir

## Primary logo
- `atelier-noir-logo.svg`: editable vector logo, square 1200×1200, designed for the homepage brand moment and social/avatar use.
- Palette: ink `#0B0B0A`, antique brass `#B9975B`, warm ivory `#F1E9DA`.
- The SVG is self-contained and can be edited directly. Keep the viewBox at 1200×1200 so it remains crisp at all sizes.

## Replacing imagery in this demo
Keep replacement assets in this folder and retain the current filenames where possible, so visual swaps do not require component edits. For a raster replacement, use WebP/AVIF for photographic imagery and preserve a high-resolution source outside the production asset folder.
